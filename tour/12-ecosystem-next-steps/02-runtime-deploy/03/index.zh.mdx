# 原生编译与条件编译

本教程使用仓颉 1.2.0 的 **CJNative** SDK，将代码编译为原生可执行文件。运行程序时需要对应平台的运行时库，或使用 SDK 支持的静态链接方式。

条件编译注解 `@When` 根据编译目标选择声明。例如，`@When[backend == "cjnative"]` 选择原生后端实现，`@When[arch == "x86_64"]` 和 `@When[arch == "aarch64"]` 选择对应处理器架构的实现。

右侧示例为不同架构声明同名的 `getArchitecture()` 函数，编译器只保留符合条件的版本。`main()` 调用这个函数，无需在运行时判断架构。

<Note>`@When` 用于选择声明，不能直接标注 `println()` 等表达式语句。本教程锁定的 1.2.0 SDK 只接受 `cjnative` 后端条件值；不要添加 `backend == "cjvm"` 分支。</Note>

修改函数返回的提示文本后运行，观察当前编译目标对应的分支。切换目标架构还需要匹配的 SDK、库与执行环境，仅修改条件不会改变编译目标。
