# Congratulations!

You have completed the Macros chapter!

This chapter covered:
- Basic concepts and working principles of macros
- How to define and use macros
- Advanced macro features (attribute matching, nesting, hygiene)
- Practical macro examples
- Macro debugging techniques

Macros are a metaprogramming tool in Cangjie. They generate code at compile time and can achieve functionality that ordinary functions cannot. Macros add complexity to code, so prefer functions when they are sufficient.
