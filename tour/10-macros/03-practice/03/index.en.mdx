# Congratulations!

You have completed the Macros chapter!

This chapter covered:
- Basic concepts of macros, macro packages, and macro parameters
- `Token`, `Tokens`, `quote` expressions, and `$()` interpolation
- Practical macro examples (such as debug-print and unit-test macros)
- Macro expansion and debugging techniques (`--debug-macro` and `diagReport`)

Macros are a metaprogramming tool in Cangjie. They generate code at compile time and can achieve functionality that ordinary functions cannot. Macros add complexity to code, so prefer functions when they are sufficient.

You can return to the module list to select the next chapter, or continue exploring other features of Cangjie.
