# Trailing Lambda

When the last parameter of a function is a function type, the lambda can be written outside the parentheses when calling. This syntax is called trailing lambda, making the code look more like built-in language syntax and improving readability.

If a function has only one parameter and that parameter is a function type, the parentheses `()` can even be omitted entirely, writing only the lambda. This is particularly useful when defining DSLs (domain-specific languages) and builder patterns.

In the example on the right, `myIf`'s second parameter is a function type, and `myIf(true) { 100 }` calls it using trailing lambda syntax. `applyTwice` has only one function parameter, so `applyTwice { value => value + 3 }` omits the parentheses and writes the lambda directly. Both forms are equivalent to conventional call syntax.

<Note>
The `=>` of a parameterless trailing lambda can be omitted. Compare the conventional call `myIf(true, { => 100 })` with the trailing form `myIf(true) { 100 }`, as well as `applyTwice { value => value + 3 }`: multi-line lambdas stay clear, while single expressions stay concise.
</Note>
