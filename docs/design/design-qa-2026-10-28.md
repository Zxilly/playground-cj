## 保留的实现差异

- 概念图外部的展示背景、圆角画板和说明标题不属于网页内容。实际界面使用可用浏览器空间，桌面编辑器区域因此更大。
- Playground 状态栏仍由编辑器显示，版本与源码链接仍在页面底部；没有复制概念图中的“代码提示已就绪”静态声明。
- 仓颉之旅的格式化、重置继续位于原生更多菜单；显式运行按钮、输出开关与更多入口使用原生工具栏。源码中的动作依然由 VS Code `ToolBar` / `Action` 管理。
- 仓颉之旅保留原生输出容器及通道行为。最终截图处于未运行、输出折叠状态，因此与概念图中的示例成功输出不同；该状态差异不作为视觉缺陷。
- 教程正文没有拆成概念图的提示卡与额外小标题。保留真实学习内容及原有顺序，避免视觉改动改变教程事实。
- 概念图未给出教程手机构图；手机验收以真实的阅读、运行、课程导航流程及桌面方向为依据。长代码行在 Monaco 内横向滚动，未强制折行或截短源代码。
